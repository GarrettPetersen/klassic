# Adrian Vale studies

```sh
npm run build:reference
npm run build:arrival
npm run serve:mvp
```

Start with the [seated reference](http://127.0.0.1:8765/web/player/?project=../../build/adrian-seated/project.json).
Open **Save, replay and animation tools → Play scene study**. The body stays fixed;
whole-arm drawings provide anticipation, an offering gesture and recovery. The
far arm crosses depth planes through complementary masks from the same drawing.
The seat and both feet remain planted.

The [arrival study](http://127.0.0.1:8765/web/player/?project=../../build/arrival/project.json)
uses the same character package. An authored path selects five strides and a
short stopping step, then an interaction sits him in the chair. After the gesture,
a second path ends with a turn toward the camera. These studies are silent;
Adrian does not yet have voice, mouth or eye overlays. The interview exercises
those features on the same runtime.

Edit `assets/production/adrian/` and canonical scene packages under
`assets/production/scenes/`. Builds only validate and export those packages. The
walking art remains a draft: it needs additional alternating footfall cels and
planted-foot registration before production acceptance. Inspect each supported
view in the [workbench](http://127.0.0.1:8765/web/review/?project=../../build/arrival/project.json).

See the [production workflow](../../docs/production-workflow.md) for registration,
independent review scopes, explicit imports, scene paths and voiced replay.
