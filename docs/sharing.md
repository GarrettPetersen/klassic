# Sharing on X

This is intended as a clearly labeled fan parody. A possible post:

> I made the Classic Krusty rerun Bart deserved: an argument about whether unions are monopolies. Unofficial fan parody; AI animation and recreated voices. Guest excerpt from Firing Line (1967); host framing is original.

Adjust that wording if the final edit uses Buckley's actual questions or different audio. Never describe newly written guest dialogue as a historical quotation. Put the source link in the post or reply. Keep a visible disclosure in the video, since it can travel without the post text. If creating a character-branded account, follow X's [parody/commentary/fan account requirements](https://help.x.com/en/rules-and-policies/authenticity); a labeled video on a personal account is a different situation.

X's [copyright policy](https://help.x.com/en/rules-and-policies/copyright-policy) allows complaints concerning uploaded images and videos. Its [fair-use page](https://help.x.com/en/rules-and-policies/fair-use-policy) does not determine whether a particular work qualifies. Labeling makes the premise clear; it does not prevent a claim or establish permission.

There are separate rights questions around the Simpsons characters, interview text/recording, and voice-reference material. Hoover's [item record](https://digitalcollections.hoover.org/objects/6008) identifies Stanford's copyright and limits reuse beyond fair use. Free access to an archive is not a public-domain dedication.

In the US, [fair use is a case-specific assessment](https://www.copyright.gov/fair-use/more-info.html). In Canada, [section 29 includes parody and satire as fair-dealing purposes](https://laws-lois.justice.gc.ca/eng/acts/C-42/section-29.html), but that does not make every derivative use fair. An original parody that comments on the borrowed material can have a stronger argument than a long, otherwise unchanged interview with a character substitution; the result still depends on the actual work and applicable law.

My practical recommendation is to finish a short, clearly attributed pilot and assess that concrete edit before building a monetized series. No X posting or account changes are automated in this repo.
