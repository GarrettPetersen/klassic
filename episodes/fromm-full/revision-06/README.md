# Superseded motion review

[Revision 07](../revision-07/README.md) replaces this preview. The user identified
that the far-hand thumbs faced inward in the seated scene, the arms were too
small, and palm-up was incorrectly used as the default cigarette hold.

The earlier anatomy checks did not catch those problems. Do not reuse the
revision-06 far-arm libraries as approved anatomy references. This directory
retains prompts for unsuccessful hand experiments. Active build, render and
review scripts have moved to revision 07.
